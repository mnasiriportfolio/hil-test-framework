A teaching book

HIL Test Framework —
The Code, Taught

This book teaches the whole codebase to someone who knows only a little programming. We read the real files — every class, protocol and algorithm — and stop to explain each object-oriented idea the first time it appears.

Analogy Think of the framework as a theatre. Layer 1 is the script (what happens), Layer 2 is the director (turns the script into actions), and Layer 3 is the cast and props (the actual instruments — or, here, stand-ins). The magic is that the script and director never need to know whether the props are real.
Scope note These chapters teach the three layers and the in-process simulated bench — the foundation everything else is built on. The other three transports (raw TCP/SCPI, PyVISA, and the DUT's binary UDP protocol), the bench emulators and the containerised bench are documented in ARCHITECTURE.md, including the wire formats. Code excerpts are abridged for teaching — type hints trimmed, bodies elided with ..., explanatory comments added — but they track the real files. Where you want the last word, the source is the authority.

How to read this book

Each chapter follows the same shape:

  • Big picture — what this part is for, in one breath.
  • Walk the code — the real source, in small pieces, with three kinds of margin notes: Why — the reasoningWhat breaks — if you got it wrongAnalogy — an everyday parallel
  • Key concepts — the OOP ideas you just met.
  • Quiz — a few questions with hidden answers.
  • Exercise — something small to try in the repo.

What you'll be able to do by the end

Explain what a Protocol is and why it lets one test suite drive both a simulator and real hardware; follow a measurement from a Robot keyword down to the simulated oscilloscope and back into a report; and add a new instrument or a new test without touching the layers above it.

Why this exists It mirrors — as a clean-room, fully-simulated project — the architecture I use for real hardware validation. No proprietary code or device details appear anywhere; every example runs on the included simulation.
