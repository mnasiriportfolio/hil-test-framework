HIL Test Framework

A layered, config-driven Hardware-in-the-Loop test framework. One set of Robot Framework suites, driven over four transports — an in-process simulation, raw TCP sockets speaking SCPI, PyVISA, and a binary UDP protocol — selected by one YAML file. The suites never learn which one they got, and the reports come out identical. Explore it three ways:
