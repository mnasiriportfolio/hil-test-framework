HIL Test Framework

A layered, config-driven Hardware-in-the-Loop test framework — with a hardware abstraction layer and a fully simulated bench that runs anywhere.

The problem

Validating measurement hardware by hand is slow, inconsistent, and hard to repeat. Wiring test logic directly to instrument addresses makes every bench a rewrite.

Three layers, one direction of knowledge

Layer 1 — Suites
Robot Framework specs. Test intent only: no code, no addresses.
▼ keywords
Layer 2 — Engine
Plans, keyword algorithms, event bus, reporting. Speaks only to interfaces.
▼ Protocol interfaces
Layer 3 — HAL
The only layer that knows how the instrument is reached. Four implementations ship.

One suite, any transport

Layer 2 talks to Protocol interfaces, so the transport is a line in a YAML file — never a code change. Four are implemented and all four run in CI:

Simulation

in-process, zero dependencies

Raw TCP / SCPI

buffered reader, IEEE 488.2 blocks

PyVISA

pyvisa-sim, pyvisa-py, or NI-VISA

Binary UDP

the DUT's own protocol, with retries

A parity test asserts a socket run and an in-process run produce byte-identical reports.

Config- and data-driven

One bench_config.yaml selects the bench. CSV plans define scenarios. Re-target to a new device by editing a spreadsheet and flipping enabled.

Five real test patterns

Line detection

Find pick-up by creeping the supply up; prove drop-out sits lower; ride through a timed supply hole.

Overcurrent, slow

RMS trigger. Detection time is a floor — tripping early is the failure.

Overcurrent, fast

Instantaneous trigger, ceiling. In AC the measured time carries the sine's own phase delay.

Harmonic

AC content on a DC line. On an AC line the same reading means nothing.

Analog output

4–20 mA loop, converted back to kV and judged point by point.

Oscilloscope-based timing

One acquisition, two probes, three intervals: stimulus → digital pin is the device deciding, pin → contact is the relay catching up, and the sum is what the outside world sees. Three limits, three measurements — one probe on the relay lets a slow contact hide inside the detection budget. The edge threshold is derived from the trace, so any relay voltage works unconfigured.

Bracket the trigger; never read it back

No trip below the window   184.3 A, relay idle     PASS
Trip above the window      216.3 A, relay driven   PASS

A tolerance claims the trip point lies inside a window. Driving the nominal trigger and checking the meter reads the nominal trigger measures the generator — it passes against a device with no detector in it. Sitting either side of the window is what pins the trip point down.

Event-sourced reporting

Keywords publish results to an event bus; a recorder subscribes and renders the report. Test logic never touches output format — add a new format without changing a single test.
